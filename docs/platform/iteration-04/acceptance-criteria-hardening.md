# Acceptance Criteria Hardening (P0/P1)

## Goal
Ensure P0/P1 items have explicit, testable acceptance criteria.

## Requirements
- Each P0/P1 item must define:
  - Preconditions
  - Expected behavior
  - Evidence artifacts (tests/logs/fixtures)
  - Failure modes
- Acceptance criteria should be referenced in iteration notes.

## Template
Use `docs/platform/iteration-04/acceptance-criteria-templates.md` and link it in item notes.

PHASE 5 – WHAT WE CLOSED
────────────────────────────
Phase 5 delivered three major structural upgrades:
Cryptographic Governance Boundary
• Teacher signs governance pins (ed25519-raw).
• Core verifies signatures before any pack resolution.
• Resolution priority is deterministic (experiment → approved → latest_stable).
• All resolution events are written to ledger.
Runtime pack selection is now cryptographically controlled and auditable.
Centralized Pin Resolver (Control Plane)
• /resolve/<pack_id> verifies signature + returns effective hash.
• /packs/* now served through governance boundary.
• Orchestrator now points to:
PACKS_BASE_URL=http://cwi-pin-resolver:8090
• Gunicorn production runtime active.
The Orchestrator no longer consumes pack artifacts directly. It must pass through governance.
Performance Baselines Captured
We established latency baselines across:
Core → pack-service (local): ~0.6 ms p50
Core → gateway path: ~2.5 ms p50
Core → Qdrant shards: ~2.0–2.1 ms p50
Core → MinIO health: ~1.9 ms p50
Orchestrator TCP connect: ~0.08 ms
ApacheBench throughput:
• ~9,300 req/sec (local)
• ~3,700 req/sec (gateway path)
These metrics place our internal mesh squarely within intra-datacenter east–west performance territory (1–3 ms class).
The network layer is not our bottleneck.
Governance is not our bottleneck.
We are inference-bound, not transport-bound.

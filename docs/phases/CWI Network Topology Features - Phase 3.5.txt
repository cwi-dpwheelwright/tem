What We Completed in Phase 3.5:
Critic Observer Mode (Non-Blocking)
The Critic runs in the background. It does not stop Teacher or Shards. It observes, analyzes, and records.
Cryptographic Pack Verification
The Critic downloads pack.json files from MinIO and computes sha256 hashes to verify integrity.
This ensures pack artifacts remain byte-accurate and unmodified.
Cross-Shard Drift Detection
The Critic samples vectors from Shard 1 and Shard 2.
It compares payload hashes using deterministic JSON normalization.
Any mismatch would be logged as drift.

# Phase 3.5 Deliverables

## 1. Critic Observer Mode (Non-Blocking)

The Critic:
- Runs independently of Teacher  
- Does not intercept publish  
- Does not halt ingestion  
- Does not modify shards  
- Only records and reports  

This matches the original CWI design philosophy: analytics without interruption.

---

## 2. Cryptographic Pack Verification

The Critic now:

- Lists pack versions in MinIO  
- Downloads pack.json  
- Computes sha256 hash  
- Records pack_sha256 in report  

Purpose:
Ensure no pack artifact is modified after publication.

---

## 3. Cross-Shard Drift Detection

The Critic:

- Pulls point IDs from Shard 1  
- Fetches same IDs from Shard 2  
- Normalizes JSON payload  
- Computes deterministic payload hash  
- Compares across shards  

If mismatch → logged under `"drift"` section.

Detects:
- Partial ingestion failures  
- Shard corruption  
- Write inconsistencies  
- Payload mutation  

---

## 4. Automated Reporting

Reports written to:

teacher-node/critic/reports/<timestamp>/critic_report.json

Each report includes:

- Timestamp  
- Qdrant health  
- Collection status  
- Pack anchor verification  
- Pack SHA verification  
- Drift sample results  
- Mismatch logs  

---

## 5. Autonomous Scheduling

Configured via systemd:

cwi-critic-scan.timer  
cwi-critic-scan.service  

Runs every 10 minutes.

- Starts after network  
- Persistent across reboot  
- No manual trigger required  

---

## 6. Least-Privilege Identity

MinIO user: critic-observer

Permissions:
- Read-only: packs/*
- Write-only: critic/reports/*
- No delete
- No publish authority

Role boundaries preserved.

# ENV_VAR_MATRIX (Authoritative)

Source of truth: `OPS/cwi-ops/env/ENV_VAR_MATRIX.json`.

This matrix defines required environment variables per deployment role. Use the validation script:

```
python OPS/cwi-ops/scripts/validate-env.py --role <role> --env-file <path/to/.env>
.\OPS\cwi-ops\scripts\validate-env.ps1 -Role <role> -EnvFile <path/to/.env>
```
